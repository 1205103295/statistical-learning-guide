逐步读代码

p_balance >= threshold逐元素比较，先得到布尔数组。astype(int)把False变成0、True变成1；约定等于阈值时归为1。

boundary公式仅对应当前一维正斜率模型、阈值0.5。预测类别变化不意味着概率突然跳变。改变阈值一般只改变决策规则，不必重新估计这些系数。
