逐步读代码

argmax返回最大值所在的位置，不是最大概率本身；位置从0开始，本例返回1，再用classes[1]取出“退款处理”。并列时argmax返回第一个最大位置，可另行约定并列规则。

scores+100给三个分数共同加常数，再用同样的稳定方法计算。allclose核验概率在浮点容差下相同。最大类别概率即使小于0.5，在相同0–1损失下仍可选它。
