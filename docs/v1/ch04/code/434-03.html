代码 4.3.4-03 · 控制相同输入后的概率与赔率比

按完整Notebook顺序运行。本章使用教学数组与给定舍入系数，尚不包含4.4；本块可能依赖前面变量。

逐步读代码

先将两个分数转换为概率；第一行学生、第二行非学生，不能凭概率高低猜行的身份。

beta_multi[3]是第4个系数，即学生系数。它的指数是保持余额和收入不变的赔率比，不能解释为因果效果。
