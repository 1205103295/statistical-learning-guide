逐步读代码

按简模型、复杂模型顺序传入。两者使用完全相同的506行响应，只差一个二次项，属于嵌套模型。

F=((RSS_R-RSS_F)/q)/(RSS_F/df_F)，这里q=1。检验的是二次项系数为0；F约177.28，p约7.47e-35，不是数学意义的0。第一行NaN是没有前一模型可比较。

经典F推断需要适当误差假设。训练拟合显著改善不等于测试误差必然改善；不能用此函数直接套在非嵌套模型或不同样本上。
