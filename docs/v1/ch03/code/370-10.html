逐步读代码

第一组一般具有不同的平方长度。第二组把v整体缩放到与u同样的欧氏长度；norm计算二范数。这样两种斜率的分母相同，分子也是同一个内积。它不要求两向量逐元素相同，也不要求完美相关。
