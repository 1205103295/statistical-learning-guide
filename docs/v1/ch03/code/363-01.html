逐步读代码

两特征加截距，设计矩阵有3列。链式 .fit() 仍是先建立模型再拟合。此处是 medv=β0+β1*lstat+β2*age+ε。

lstat系数解释为保持age不变时的线性关联，不能拿来代替因果效应。与简单回归系数不同，是因为控制变量变了。
