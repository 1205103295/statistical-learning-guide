逐步读代码

Carseats是400个地点的儿童安全座椅销量数据，Sales单位千件。ShelveLoc是陈列位置质量：Bad、Medium、Good，不能简单当连续数值0、1、2。dtype 查看数据类型；value_counts() 统计每类数量。

分类变量需要合适编码。含截距时k个类别通常使用k-1个指示变量，以免完全共线；删去哪一列决定参考组。
