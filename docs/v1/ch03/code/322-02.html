逐步读代码

  • H 将观测投影到设计矩阵列空间，M 留下正交补部分。两者形状均为 (n, n)。
  • 三个断言分别检查幂等性、残差投影消去模型列、以及投影残差与直接计算相同。
  • np.trace 求对角线之和；y_multi @ M @ y_multi 是标量二次型，数值等于 RSS。

实际运行输出

trace H, trace M: [3. 1.]
RSS from projection: 0.3
