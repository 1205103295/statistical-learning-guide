逐步读代码

这里 ssr 指残差平方和RSS；不要把属性名误解成回归解释平方和。scale 是RSS/残差自由度，即s²；开方才是RSE。在含截距、满秩情形，自由度是n-p-1，p为输入项数。

R²衡量当前拟合数据上的平方误差改善；调整R²惩罚参数增加。整体F检验所有非截距系数同时为0。它们都不是独立测试误差，也不能单独证明模型假设成立。
