逐步读代码

np.abs 对每个差取绝对值；一维欧氏距离就是绝对差。np.argsort 返回距离从小到大的位置，而不是距离本身；[:3] 取前三个位置。用同一组位置选择输入和响应，再对响应求平均。邻居只由输入决定，没有使用目标值来选择。

实际运行输出

neighbor positions: [2 3 1]
neighbor inputs: [30. 40. 20.]
prediction: 7.666666666666667
