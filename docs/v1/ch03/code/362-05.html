mean 是预测平均值；mean_se 是平均响应估计的标准误；mean_ci_lower/upper 是平均响应置信区间；obs_ci_lower/upper 是一个新地区medv的预测区间。此处“个体”是新的一行/地区，不是一套房子。

相应方差为 s²h0 和 s²(1+h0)，所以后者更宽。区间依赖模型假设；下文发现曲线形态，提示简单直线不充分，软件给出的区间不能无条件信任。
