逐步读代码

degree=2 指最高二次；raw=True 明确生成原始lstat与lstat²两列。加age和截距，共4个参数。

模型β0+β1*lstat+β2*lstat²+β3*age，对输入非线性，但对未知系数线性，仍可用OLS。此处提前明确raw=True，方便直接解释系数；教材默认正交多项式，下一块会比较。
