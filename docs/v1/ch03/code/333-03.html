逐步读代码

  • 前五点沿原关系分布，最后一点输入很远且偏离原趋势；此实验用于展示拉动拟合后的残差可能不大。
  • Xi @ pinv(Xi) 得到列空间正交投影，diag 取每个训练点的杠杆值。[:-1] 选择除最后一行以外的全部数据。
  • 删除最后一点后重新求最小二乘，再比较系数，而非只把它的残差去掉。最后一行通过 [-1] 读取该点在完整模型中的残差。
