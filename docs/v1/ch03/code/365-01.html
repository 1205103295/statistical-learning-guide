逐步读代码

列表中字符串表示主效应，元组 ('lstat','age') 告诉MS创建两变量乘积项。模型为β0+β1*lstat+β2*age+β3*lstat*age。

固定age=a时，lstat的斜率是β1+β3*a。不能把β1看成所有地区共同的斜率；β1对应age=0时。保留主效应有助于遵循模型层级原则。
