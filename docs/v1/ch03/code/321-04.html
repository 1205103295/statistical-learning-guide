逐步读代码

  • copy() 创建独立数组，避免改动原响应。索引 [-1] 取最后一个元素，+= 0.01 表示在原值上加 0.01。
  • lstsq(...)[0] 只取返回元组中的系数。svd(..., compute_uv=False) 只求奇异值，不返回左右奇异向量；奇异值从大到小排列。
  • sv[0] / sv[-1] 计算最大与最小奇异值之比。最后显示的平方利用满列秩矩阵的理论恒等式，没有为了求系数直接计算病态正规方程的逆。
