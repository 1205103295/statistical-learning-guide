运行方式

在 VS Code 中打开 Notebook，选择安装了 NumPy、Matplotlib、SciPy 和 IPython 的 Python 内核，从上到下运行。将 Notebook 所在目录作为工作目录，图片会保存到“图片”文件夹。

核验环境：Python 3.10.20；NumPy 2.2.6；Matplotlib 3.10.8；SciPy 1.13.1。通过新的 Jupyter 内核实际运行，结果保存在 Notebook 中。
