代码 2.4-28 · 第8(f)：构造Elite并核对边界

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • pd.cut按边界把Top10perc划分为两组；默认右端包含，include_lowest=True额外包含最左端0，所以区间为0至50（含两端）、大于50至100。
  • labels=["No","Yes"]按区间顺序命名，赋给新列Elite；这是类别列，不是模型预测。
  • 第一条assert检查Elite没有缺失：.notna()逐行判断，.all()要求所有行都为真。超出边界或原值缺失都会使这项检查失败。
  • 第二条先分别生成“Elite为Yes”和“Top10perc大于50”的布尔Series，再用.equals()核对逐行结果相同；这能检查分箱边界是否符合定义。
  • value_counts().to_string()打印各组数量；这里50表示50%，不是0.5。
