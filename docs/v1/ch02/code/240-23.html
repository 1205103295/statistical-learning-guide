代码 2.4-23 · 第8(b)：用两种方法设置学校索引

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • index_col=0在读入时把第一列设为行索引。另一种写法先用.columns[0]取得第一列名，再以字典传给rename(columns=...)改名为College。
  • set_index("College")把该列移到索引，默认从普通列中移除；两种路径最终应得到相同的表格内容。
  • college2.equals(college3)返回内容、行列对应是否相等的布尔值；外层assert要求它为真，否则报错。它不要求本例两者的索引名称元信息相同。
  • .copy()保存后续使用的副本；.index.is_unique检查学校索引是否重复，.columns[:4].tolist()把前四个列名列出来。打印唯一性只是报告，并未自动删除重名行。
