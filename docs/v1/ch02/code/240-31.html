代码 2.4-31 · 第8(h)：检查偏态、相关与可疑毕业率

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • 双层方括号选Apps和Expend两列；.agg(["mean","median"])分别计算均值与中位数，帮助识别偏态。
  • college["Apps"].corr(college["Enroll"])计算两列的Pearson相关系数，round(...,4)仅控制打印精度。
  • loc[条件,[列名]]先按毕业率大于100筛行，再保留毕业率列；因为列名放在列表中，结果仍是DataFrame，学校索引也保留。
  • to_string()完整打印这些待核查记录。筛选只是把问题展示出来，并未删行或自动改值。
