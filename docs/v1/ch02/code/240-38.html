逐步读代码

  • 选取五列建立5×5散点矩阵，axes[0,0]是左上角对角图。后续三行专门整理这一格的刻度文字，不改变数据。

  • 从绘图区取整图，调整布局，再保存、显示和关闭。labels与刻度位置必须一一对应。
