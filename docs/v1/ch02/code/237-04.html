逐步读代码

  • feature_columns是两个列名组成的列表，target_column是一个字符串；[target_column]把字符串包成单元素列表，才能与特征列表用+连接。
  • dropna(subset=required_columns)只检查指定三列，只要其中一列缺失便删除该行；其他未指定列不参与判断。
  • .copy()取得独立副本用于后续操作；原始df仍保留。打印clean核对留下的车辆和原始行标签。
