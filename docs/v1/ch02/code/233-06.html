按轴求和与求均值

这一块属于连续的 Notebook。请先运行前面的代码块；变量可能依赖前面的定义。全部数据均为教学用虚构数据。

代码 2.3.3-06

逐步读代码

  • contributions.sum(axis=1)沿列轴汇总，即每行把所有特征贡献加起来，得到三个数。
  • X.mean(axis=0)消去样本轴，为每列算一个均值，结果(2,)；axis=1消去特征轴，为每行算一个均值，结果(3,)。
  • .shape核对汇总后的形状；不同单位的特征虽然能按行取均值，但这个平均值未必有业务意义。
