代码 2.1.2-02

逐步读代码

  • np.array(...)把列表变为数组。外层列表的每个元素是一行；[[10.0], ...]保留“样本、特征”两个轴，因此输入是五行一列。
  • y_train只用一层列表，形状为(5,)；X_new即使只有一个数，也写成[[25.0]]，使预测接口收到(1,1)输入。
  • print(说明文字, 对象)依次打印说明与值；.shape是属性，直接读取，不加调用括号。三项输出用于核对输入与目标是否匹配。

实际运行输出

X_train shape: (5, 1)
y_train shape: (5,)
X_new shape: (1, 1)
