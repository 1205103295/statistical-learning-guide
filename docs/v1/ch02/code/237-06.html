逐步读代码

  • clean[feature_columns]按列表顺序选两列；clean[target_column]取一列目标。它们来自同一张表，保留相同样本顺序。
  • .to_numpy(dtype=float)转成浮点NumPy数组，不再携带表格行标签和列名。分别得到(3,2)与(3,)，所以转换前应先确认对齐。
