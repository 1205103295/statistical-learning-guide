代码 2.4-10 · 固定选择并检查训练参数

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • scores["validation_mse"]取验证误差列；.idxmin()返回最小值所在的行标签，也就是方法名，不是最小误差值。并列时取当前顺序中的第一个。
  • models["knn5"]从字典取KNN流水线；.named_steps["standardscaler"]再从步骤映射中取标准化器。这个步骤名由make_pipeline生成。
  • .mean_与.scale_是已经fit得到的训练均值和缩放尺度；末尾下划线提示这是拟合后属性。
  • np.allclose(a,b)允许浮点误差，在默认容差内逐项比较两组数并汇总成真假；外层assert要求比较通过。这里用ddof=0与StandardScaler的标准差定义保持一致。
  • 检查KNN的预处理是否正确，与最终是否选中KNN是两回事；本次验证选择的是线性回归。
