代码 2.4-42 · 第10(e)：查看高犯罪率、税率与师生比记录

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • 循环变量column依次为crim、tax、ptratio；nlargest(3,column)按当前列取值最大的三行，默认并列按原顺序取前面的记录。
  • 后面的[[column]]只保留当前这一列，同时保持二维表格。它没有删除原数据的其他列。
  • 每轮先打印当前排序依据，再打印对应行标签与值；同一个地区可能在多个变量的前三名中出现。
