这一块属于连续的 Notebook。请先运行前面的代码块；变量可能依赖前面的定义。全部数据均为教学用虚构数据。

代码 2.3.3-04

逐步读代码

  • reshape(3,1)和reshape(1,3)重新组织同样三个元素，分别返回列形状和行形状；元素总数必须保持一致。
  • reshape(-1,1)只指定一列，行数自动计算；reshape(-1)把数组展为一维。代码把返回对象赋给新名字，所以最后的v.shape仍是(3,)。

实际运行输出

[[10.]
 [20.]
 [30.]]
[[10. 20. 30.]]
(3, 1)
(3,)
(3,)
