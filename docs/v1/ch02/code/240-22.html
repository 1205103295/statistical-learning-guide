代码 2.4-22 · 第8(a)：读取含学校名称的官方CSV

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • 先用路径与网址定位College文件；if not ...exists()仅在本地不存在时下载。urlopen(...).read()读取字节，write_bytes保存，网络失败会抛出异常。
  • pd.read_csv(college_path)按逗号读取整表。iloc[:3,:4]按位置取前三行前四列，便于检查学校名称在哪一列。
  • to_string(index=False)把所选小表完整转换为文本，并隐藏额外的行索引；它不删除原表中的学校名称列。
