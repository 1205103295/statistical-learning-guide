代码 2.4-02 · 定位官方数据并记录校验值

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • source_url保存网址字符串；data_dir / "Auto.data"把目录与文件名拼成路径，/在这里不是数值除法。
  • .exists()判断路径是否存在；not把真假取反。只有本地文件不存在时才进入if下载，避免重复覆盖已有数据。
  • with urlopen(...,timeout=30) as response:打开网络响应并命名为response；with结束时会关闭资源。timeout限制网络操作等待，失败会报错，不会凭空生成数据。
  • response.read()取得字节内容，write_bytes写到磁盘。随后read_bytes()读取本地文件，sha256(...).hexdigest()生成十六进制校验字符串，用于核对文件是否相同，不是验证数据一定正确。
