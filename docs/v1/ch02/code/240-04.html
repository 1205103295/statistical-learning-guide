逐步读代码

  • feature_columns是输入列名列表，target_column是目标列名字符串；[target_column]把字符串包为列表，+连接后得到要检查的三列。
  • auto.dropna(subset=required)删除这三列中任一列缺失的行；.copy()保存副本，不改原始auto。先统一筛选整表，再拆出X和y，避免样本错位。
  • 用列表选列得到二维DataFrame，用字符串选一列得到一维Series。len(auto)、len(X)和它们的差分别是原始、保留、删除的行数；形状输出应为(392,2)与(392,)。
  • assert 条件称为断言：条件为真时安静通过；为假时抛出AssertionError并停止当前单元格。X.index.equals(y.index)比较两组行标签及其排列顺序，核对特征与目标是否对齐。
  • X.notna()把非缺失位置变为真；第一次.all()检查每一列是否全部为真，得到按列排列的Series；第二次.all()再检查所有列，得到一个布尔值。
  • y只有一维，所以y.notna().all()一次即可汇总。and要求输入和目标两边都通过；缺失检查不能证明数值单位正确或没有无穷值。断言用于开发核对，不能替代生产程序必需的输入校验。
