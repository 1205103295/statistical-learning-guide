代码 2.4-30 · 第8(g)：比较不同变量和分箱数

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • subplots(2,2)生成二维绘图区数组；axes.flat把四个位置按行依次遍历，便于写一个循环。
  • settings每项是“列名、箱数”的二元组。for ax, (column,bins) in zip(...)先接收图区，再把另一项拆为列名与箱数，是嵌套解包。
  • college[column].plot.hist(...,ax=ax)在当前图区画直方图，edgecolor="white"用白线分开柱子；f字符串把变量和箱数写入标题。
  • Apps分别画10箱和30箱，另外两格画不同变量。最后保存的是包含四格的整图，不是分别保存每个图区。
