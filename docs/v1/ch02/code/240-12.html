代码 2.4-12 · 计算最终测试指标

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • final_model.predict(X_test)生成最终预测；mean_squared_error得到MSE，np.sqrt开平方得到RMSE。
  • np.abs(y_test.to_numpy()-final_pred)逐项取绝对误差，再求均值得MAE。使用相同顺序的一维数组，避免索引或广播造成误算。
  • DummyRegressor(...).fit(...)把创建和拟合连写；fit返回拟合后的对象，于是baseline_final可以直接predict。基准也只使用开发目标学习。
  • round(数值,4)用于打印四位小数，不改原指标。这一块只报告固定方案及事先约定的基准，不在测试结果中重新挑选候选。
