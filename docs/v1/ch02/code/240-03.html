代码 2.4-03 · 读取字段、类型和缺失数量

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • pd.read_csv也能读其他分隔符的文本；sep=r"\s+"用正则表达式表示一个或多个空白字符，前缀r让反斜杠按原样交给解析器。
  • na_values=["?"]把问号识别为缺失。auto.shape报告整表行列数，auto.dtypes逐列报告类型。
  • auto.isna()产生缺失位置布尔表；.sum()默认沿样本轴按列计数，因此输出的是每列缺失数，不是每辆车缺几项。
