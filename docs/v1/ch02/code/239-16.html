逐步读代码

  • 分别将同一份验证目标与两组预测比较，得到两个MSE；只有比较相同样本与指标才有意义。
  • "linear" if 条件 else "baseline"是条件表达式：线性MSE严格更小时选线性，否则选基准，相等也走else。
  • chosen_method保存方法名称字符串，不是已经重训的模型；下一块据此决定执行哪个分支。
