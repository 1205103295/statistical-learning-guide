代码 2.3.7-02

逐步读代码

  • StringIO(csv_text)把文本包装成可读取对象，pd.read_csv解析逗号分隔字段；na_values=["?"]把问号转换为缺失值。
  • head()默认查看前五行，不会删掉第六行；.shape仍报告完整表的行列数。
  • .columns保存列标签，.tolist()把它转成普通列表；.dtypes按列显示类型，用来发现本应为数值的列是否被读成了文字。
