  • 此处重新给X赋值，旧的三行两列数组被这个四行三列数组替代。后面的索引均针对新X。
  • 索引从0开始，X[0,0]取第一行第一列，X[1,2]取第二行第三列。
  • 1:3取位置1、2，:2取位置0、1；切片包含起点、不包含终点，所以结果是两行两列。
