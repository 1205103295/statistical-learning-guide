代码 2.3.3-05

逐步读代码

  • beta按特征列顺序保存两个系数。X*beta通过广播把每行的两个特征分别乘对应系数，结果仍为(3,2)，每格是一个特征的贡献。
  • X @ beta执行矩阵与向量乘法，把每行贡献加起来，返回(3,)。再加标量截距5时，5会加到每个预测上。
  • y_pred每个元素对应一个市场，预测数量由样本行数决定，不由系数数量决定。
