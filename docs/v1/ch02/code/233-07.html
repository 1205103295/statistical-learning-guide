代码 2.3.3-07

逐步读代码

  • y_true-y_pred逐个计算真实值减预测值；先用**2平方，再用np.mean取平均，才得到MSE。正负误差因此不会相互抵消。
  • assert 条件是断言：条件为真时不输出，条件为假时抛出AssertionError，停止当前单元格后续执行。这里==比较两组形状是否相同，区别于赋值用的=。
  • 这条检查在本例计算之后起核对作用；自己写程序时通常应在相减之前检查形状，以更早阻止错误广播。形状一致也不自动证明样本顺序正确。
