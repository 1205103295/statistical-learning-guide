代码 2.4-21 · 分别检查一个与三个邻居的投票

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • 循环让k先取1再取3；order[:k]截取最近的k个行位置，y_knn[...]按这些位置提取标签。
  • pd.Series(neighbor_labels).value_counts()统计各标签出现次数，结果的索引是类别、值是次数。
  • .idxmax()返回计数最大的类别名，因此可作为多数投票预测。本题没有并列；一般遇到并列时应明确规则，而不是把偶然返回顺序当成业务依据。

实际运行输出

K = 1 neighbors: ['Green']
prediction: Green
K = 3 neighbors: ['Green', 'Red', 'Red']
prediction: Red
