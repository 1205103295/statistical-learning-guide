代码 2.4-34 · 第9(d)：按行位置移除第10至85条

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • np.ones(len(auto_full),dtype=bool)生成与数据等长、初始全部为真的位置掩码；keep[9:85]=False把位置9到84改为假，恰对应从1计数的第10至85条。
  • iloc[keep]接受这个NumPy布尔数组，按位置保留真所在行；这与带索引的pandas布尔Series不同，不需要按标签对齐。
  • 对保留数据重新计算四项统计量及span；并非在旧摘要表上减去被删记录的统计量。
  • ~keep逐元素取反，真表示刚才被排除的位置；.sum()把真按1计数，得到删除76行，剩余316行。
