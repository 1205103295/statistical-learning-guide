代码 2.4-20 · 计算每个样本到原点的距离

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • X_knn每行一个样本、每列一个坐标；y_knn按相同行序保存颜色标签。目标点是原点，所以坐标本身就是到原点的各维差值。
  • X_knn**2逐元素平方，np.sum(...,axis=1)把每行三项加起来，np.sqrt逐项开方，得到长度6的距离数组。
  • np.argsort(distance)返回按距离从小到大排列的行位置，不是排序后的距离本身。输出order+1只是把从0起算的位置改为题目从1起算的编号。
