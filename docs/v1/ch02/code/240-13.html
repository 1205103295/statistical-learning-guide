代码 2.4-13 · 保存逐车预测与残差

按Notebook顺序运行。后续代码依赖前面定义的变量。真实数据来自教材官网。

逐步读代码

  • 字典中的name按测试行标签从完整表取车型名，actual保存真实目标，predicted保存预测数组；index=X_test.index规定结果表的行身份和顺序。
  • 带索引的Series按标签对齐；没有索引的预测数组按位置填入。因此预测必须来自这份同顺序的X_test，不能随意打乱。
  • 新增residual列是实际值减预测值。双层方括号按指定顺序选三列，head()只看前五行，round(3)只简化显示。
  • to_csv(...,index_label="row_id")保存完整结果及原行标签，便于追踪每辆车，而不仅保存屏幕上的五行。
