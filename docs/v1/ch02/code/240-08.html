逐步读代码

  • models是“方法名称→模型对象”的字典；冒号左边的字符串用于识别方法，右边创建相应对象。
  • DummyRegressor(strategy="mean")在fit时学习目标均值；LinearRegression()学习线性系数；KNN的n_neighbors=5固定取五位邻居。
  • make_pipeline(StandardScaler(), KNeighborsRegressor(...))按顺序连接预处理与模型。对整体调用fit会先学习训练均值、标准差并转换输入，再拟合KNN；predict会自动使用同一套转换。
  • 此时只是定义三种候选，没有读取验证或测试目标来决定参数。
