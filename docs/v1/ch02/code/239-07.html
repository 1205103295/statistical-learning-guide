逐步读代码

  • train_test_split(X,y,...)使用同一套行划分同时拆分输入与目标；左边四个变量的顺序必须与返回顺序对应。
  • test_size=0.25留出四分之一的行，random_state=42固定随机划分以便复现；12行得到9行训练、3行测试。
  • .index.to_list()打印原行标签，帮助检查哪些车辆分到哪组。标签保留原样，不会因随机划分重新编号。
